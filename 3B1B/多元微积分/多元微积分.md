# 偏导

$$\begin{align*}
\frac{\partial f}{\partial x}(x,y) &= \frac{\partial}{\partial x}\big(x^2 y + \sin(y)\big) \\\\
&= 2xy + 0 \\\\
\frac{\partial f}{\partial y}(x,y) &= \frac{\partial}{\partial y}\big(x^2 y + \sin(y)\big) \\\\
&= x^2 + \cos(y)
\end{align*}$$

将另一个值看成固定值并求导

$$\frac{\partial f}{\partial y}(a,b) = \lim_{h \to 0} \frac{f(a,b+h)-f(a,b)}{h}$$

$$\frac{\partial f}{\partial x}(a,b) = \lim_{h \to 0} \frac{f(a+h,b)-f(a,b)}{h}$$

对求出来的结果再求导，平方仅仅是代表多层求导，在公式里不是计算意义。

# 方向导数

这里的 $`a,b`$ 是单位方向向量 $`\vec{u}=(a,b)`$ 在 $`x,y`$ 平面上的分量，方向导数公式只是说明如何计算；它相当于把梯度投影到 $`\vec{u}`$ 方向上，所以上升速度不会比原始梯度快。

$$\nabla_{\vec{u}} f = a\frac{\partial f}{\partial x}+b\frac{\partial f}{\partial y}$$

图像仍然落在原函数曲面上，只不过上升速度小于等于梯度方向的速度。

根据分析，当 $`\vec{v}`$ 的方向与梯度方向一致时，方向导数最大，所以直接把最大值代入。这里的 $`(a,b)`$ 是求梯度的点坐标；$`\vec{v}`$ 被拆解成了括号里的单位向量 $`\frac{\nabla f(a,b)}{\Vert\nabla f(a,b)\Vert}`$。

$$\max_{\Vert\vec{v}\Vert=1} \nabla f(a,b) \cdot \vec{v} = \nabla f(a,b) \cdot \left( \frac{\nabla f(a,b)}{\Vert\nabla f(a,b)\Vert} \right) = \frac{\Vert\nabla f(a,b)\Vert^2}{\Vert\nabla f(a,b)\Vert} = \Vert\nabla f(a,b)\Vert$$

最大方向导数的值等于梯度的模长；$`\vec{v}`$ 取梯度方向时，梯度既带方向又带长度。

### 另一种方法
#### 不是很严谨的说法

### 转换成单变量结果形式

$$\begin{aligned}
\frac{d}{dt} f(x(t), y(t)) &= \frac{\partial f}{\partial x} \cdot \frac{dx}{dt} + \frac{\partial f}{\partial y} \cdot \frac{dy}{dt} \\\\
&= \begin{bmatrix} \partial f / \partial x \\\\ \partial f / \partial y \end{bmatrix} \cdot \begin{bmatrix} dx / dt \\\\ dy / dt \end{bmatrix} \\\\
&= \nabla f \cdot \vec{v}'(t) \\\\
&=\nabla f(\vec{v}(t)) \cdot \vec{v}'(t)
\end{aligned}$$

梯度f的自变量就是位置向量。

$`\vec{v}'`$位置向量的导数，位置向量关于时间变化，给定微小的t,得到一个方向。

这个时候f可以是无限维函数

又因为

$`\nabla_{\vec{w}} f(\vec{p}) = \nabla f(\vec{p}) \cdot \vec{w}`$

左边的三角形符号是方向导数，不要理解成梯度了，课程中是写成了一样的，正确如下。

$`D_{\vec{u}} f(\vec{p}) = \nabla f(\vec{p}) \cdot \vec{u}`$

函数在某一点沿某个方向的变化率（方向导数），等于该点的梯度向量与这个方向向量的点积(标准方向导数公式中，u长度为1)。

代入可得

$`\nabla_{\vec{v}'(t)} f(\vec{v}(t)) = \nabla f(\vec{v}(t)) \cdot \vec{v}'(t)`$

不过另一点，这个w不是最开始得到这个公式的时候的做过规范化的w,长度会大于或者小于1，最终点乘值可以超过梯度值。
### 多元链式法则正式证明

$$\frac{d\vec{v}}{dt}(t) = \lim_{h \to 0} \frac{\vec{v}(t+h) - \vec{v}(t)}{h}$$

$$\frac{d\vec{v}}{dt}(t)h = \underbrace{\vec{v}(t+h) - \vec{v}(t)}_{d\vec{v}} + \underbrace{h E(h)}_{o(h)}$$

h逼近0的情况下：

$$\frac{\Vert E(h)\Vert}{h} \to 0$$

移项(o(h)极小项，不纠结正负号)：

$${\vec{v}(t+h) = \vec{v}(t) + \frac{d\vec{v}}{dt}(t)h + o(h)}$$

将上一步代入

$$\lim_{h \to 0} \frac{f(\vec{v}(t+h)) - f(\vec{v}(t))}{h} = \lim_{h \to 0} \frac{f\left(\vec{v}(t) + \frac{d\vec{v}}{dt}(t)h + o(h)\right) - f(\vec{v}(t))}{h}$$

$$= \nabla_{\vec{v}'(t)} f(\vec{v}(t))$$

#### $`\nabla_{\vec{v}'(t)} f(\vec{v}(t))`$如何得到

多元函数的线性近似

这个相当于一阶泰勒展开，使用约等于是因为还差更高阶的无穷小

$$f(a + \Delta x) \approx f(a) + \nabla f(a) \cdot \Delta x$$

后面的是多元函数的梯度点乘x点的位移向量

将下面公式看成多元函数展开的形式

$$f\left(\vec{v}(t) + \frac{d\vec{v}}{dt}(t)\thinspace h + o(h)\right)$$

基准点 $`\vec{a}`$ 就是 $`\vec{v}(t)`$

微小增量 $`\Delta\vec{x}`$ 就是 $`\dfrac{d\vec{v}}{dt}(t)\thinspace h + o(h)`$

将上面的近似代入到极限分子中再使用一阶泰勒展开

$`f\left(\vec{v}(t) + \frac{d\vec{v}}{dt}(t)h + o(h)\right) - f(\vec{u}(t))`$

$`f(\vec{a} + \Delta\vec{x}) - f(\vec{a} ) \approx \left[ f(\vec{a} ) + \nabla f(\vec{a} ) \cdot \Delta\vec{x} \right] - f(\vec{a} )`$

$`f(\vec{a}  + \Delta\vec{x}) - f(\vec{a})  \approx \nabla f(a) \cdot \Delta x`$

将代入的值代回原值(公式A)

$$\approx \nabla f(\vec{v}(t)) \cdot \left( \frac{d\vec{v}}{dt}(t)h + o(h) \right)$$

利用点乘的分配律，把这个内积展开(公式B)

$$= \left[ \nabla f(\vec{v}(t)) \cdot \frac{d\vec{v}}{dt}(t) \right] h + \nabla f(\vec{v}(t)) \cdot o(h)$$

回到极限式子，把上面的结果代进去：

$$\lim_{h \to 0} \frac{f(\vec{v}(t+h)) - f(\vec{v}(t))}{h} =
\lim_{h \to 0} \frac{
\left[ \nabla f(\vec{v}(t)) \cdot \frac{d\vec{v}}{dt}(t) \right] h + \nabla f(\vec{v}(t)) \cdot o(h)
}{h}$$

把分母的 $`h`$ 除进去，分成两部分：

$$= \lim_{h \to 0} \left( \nabla f(\vec{v}(t)) \cdot \frac{d\vec{v}}{dt}(t) + \frac{\nabla f(\vec{v}(t)) \cdot o(h)}{h} \right)$$

余项$`o(h)`$除以$`h`$在$`h->0`$取极限后为$`0`$,左边没有h项，保留原式

$$\nabla f(\vec{v}(t)) \cdot \frac{d\vec{v}}{dt}(t)$$

$$= \nabla_{\vec{v}'(t)} f(\vec{v}(t))$$

公式A三维表示

乘号左边
$`\nabla`$(梯度)f(U(t输入t得到一个多维向量)输入多维向量的多元函数)
乘号右边
实际位移 = 切向线性主部 + 高阶弯曲修正

公式B改成等号

右边加上$`o(h)`$(更高阶无穷小)可以换成等号(当前位置无用，仅作为换等于号的知识点)
关于等式右边两个o(h)，内部是多维向量的高阶无穷小量，外部是多元函数高阶无穷小量

$$f\left(\vec{v}(t) + \frac{d\vec{v}}{dt}(t)h + o(h)\right) - f(\vec{v}(t)) =
\nabla f(\vec{v}(t)) \cdot \left( \frac{d\vec{v}}{dt}(t)h + o(h) \right) + o(h)$$

# 曲率

### $`k=\left\Vert \frac{d\vec{T}}{ds} \right\Vert`$曲率原始定义

错误

T是切线，用弧度角度概念对比，可以认为是弧度，s相当于弧长

弧度*半径=弧长

s/T=R

T/s=1/R

### 单位切向量T(t)

原函数：

$$\vec{S}(t) = (R\cos t,\thickspace R\sin t)$$

错误

求导得速度向量(模长：速率$`ds/dt`$，也是导数+方向：单位切向量)：

$$\vec{S}'(t) = (-R\sin t,\thickspace R\cos t)$$

计算其模长得到速率 $`\frac{ds}{dt}`$：

$$\Vert\vec{S}'(t)\Vert = \sqrt{(-R\sin t)^2 + (R\cos t)^2} = \sqrt{R^2(\sin^2 t + \cos^2 t)} = \sqrt{R^2} = R$$

规整化（除以模长）得到单位切向量 $`\vec{T}(t)`$

$$\vec{T}(t) = \frac{\vec{S}'(t)}{\Vert\vec{S}'(t)\Vert} = \frac{(-R\sin t,\thickspace R\cos t)}{R} = (-\sin t,\thickspace \cos t)$$

通用形式下这个将会是
$`\vec{T}(t) = \left( \frac{x'(t)}{\sqrt{x'(t)^2 + y'(t)^2}}, \frac{y'(t)}{\sqrt{x'(t)^2 + y'(t)^2}} \right)`$

### ds弧长的微分

这个和T很难对应，复杂的积分

直接用导数S'(t)的模长得到ds/dt

一个导数的模长正好等于另一个导数，直接将得到的东西往曲率原始定义硬塞

### 从弧长定义到参数计算的桥梁

$`\kappa = \left\Vert \frac{d\vec{T}}{ds} \right\Vert = \left\Vert \frac{d\vec{T}/dt}{ds/dt} \right\Vert = \frac{\left\Vert \frac{d\vec{T}}{dt} \right\Vert}{\left| \frac{ds}{dt} \right|} = \frac{\left\Vert \frac{d\vec{T}}{dt} \right\Vert}{\left\Vert \frac{d\vec{S}}{dt} \right\Vert}`$

**1.核心恒等式（弧长变化率 = 速度向量的模长）**

几何定义（用弧长 $`s`$）：$`\kappa = \left\Vert \frac{d\vec{T}}{ds} \right\Vert`$

**2.链式法则，转化为对参数 $`t`$ 求导：**

对于一个向量 $`\vec{v}`$ 和一个非零实数 $`c`$，有：

$$\left\Vert \frac{\vec{v}}{c} \right\Vert = \frac{\Vert\vec{v}\Vert}{|c|}$$

“先把向量缩小 $`c`$ 倍，再求长度”，和“先求长度，再把这个长度除以 $`c`$ 的绝对值”，结果是一样的。

由以上公式可得：

$$\kappa = \left\Vert \frac{d\vec{T}/dt}{ds/dt} \right\Vert = \frac{\left\Vert \frac{d\vec{T}}{dt} \right\Vert}{\left| \frac{ds}{dt} \right|}$$

**3.把分母的小写 $`\frac{ds}{dt}`$ 替换为大写 $`\left\Vert \frac{d\vec{S}}{dt} \right\Vert`$（因为它们是相等的）：**

#### TODO这个不是定义，有推导

ds/dt永远是非负数

$$\frac{ds}{dt} = \left\Vert \frac{d\vec{S}}{dt} \right\Vert$$

$$\kappa = \frac{\left\Vert \frac{d\vec{T}}{dt} \right\Vert}{\left\Vert \frac{d\vec{S}}{dt} \right\Vert}$$

**4.计算例子**

依然以 $`\vec{S}(t) = (R\cos t,\thickspace R\sin t)`$ 为例。

$$\left\Vert \frac{d\vec{T}}{dt} \right\Vert = \sqrt{(-\cos t)^2 + (-\sin t)^2} = \sqrt{\cos^2 t + \sin^2 t} = \sqrt{1} = 1$$

$$\frac{ds}{dt} = \left\Vert \frac{d\vec{S}}{dt} \right\Vert = R$$

$$\kappa = \frac{\left\Vert \frac{d\vec{T}}{dt} \right\Vert}{\left\Vert \frac{d\vec{S}}{dt} \right\Vert} = \frac{1}{R}$$

特殊圆形（半径 $`R`$）的速率是常数，计算比较简单，最终曲率结果为 $`\frac{1}{R}`$

### 一般参数方程曲线的曲率公式

#### TODO这个不是定义，有推导

对于参数方程 $`x = x(t)`$，$`y = y(t)`$，其曲率 $`\kappa`$ 的通用计算公式为：

**标准形式（带绝对值，表示弯曲程度，恒为非负数）：**

$$\kappa = \frac{|x'(t)y''(t) - y'(t)x''(t)|}{\left( x'(t)^2 + y'(t)^2 \right)^{3/2}}$$

**带符号形式（去掉绝对值，正负号表示弯曲方向）：**

$$\kappa = \frac{x'(t)y''(t) - y'(t)x''(t)}{\left( x'(t)^2 + y'(t)^2 \right)^{3/2}}$$

**符号说明：**
*   $`x'(t), y'(t)`$：函数对参数 $`t`$ 的**一阶导数**（构成速度向量）。
*   $`x''(t), y''(t)`$：函数对参数 $`t`$ 的**二阶导数**（构成加速度向量）。
*   **分子**：一阶导和二阶导的“二维叉积”（$`x'y'' - y'x''`$）。
*   **分母**：速度向量模长的三次方，即 $`\left( \Vert\vec{S}'(t)\Vert \right)^3`$。
